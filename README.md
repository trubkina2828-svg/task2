# Семинарское занятие №2-1

**ФИО:** Трубкина Н.А.

**Группа:** ПИ24-2в 

**Задача:** Java (Spring Boot + ORM), MySQL, HTML/CSS/JS. Реализовать веб-систему «Склад магазина техники» с авторизацией.

**Вариант:**  Н–Т:  вид_техники (кириллица), по двум полям (дата ввоза + вид), 30 дней; 

---
## Необходимый функционал:
CRUD техники, поиск, сортировка по дате ввоза на склад, гистограмма количества отгруженной (вывезенной) техники по дням (по дате вывоза), счётчик записей в таблице.

## Параметры объекта: 
ID, Вид техники, Группа техники, Дата ввоза, Дата вывоза, ФИО водителя.
